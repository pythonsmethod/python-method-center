# WEB PLATFORM POLICY

## Purpose

This document establishes the official platform strategy of Python Method Center.

It exists so that future development of the Center remains consistent with a single, deliberate architectural direction.

## Core Principle

Python Method Center develops as a web platform.

The website is the primary environment of the Center.

## Architectural Rules

- The website is the main user interface.
- New user journeys must be designed for the website first.
- AI interaction must occur inside the web platform.
- Navigation must occur inside the web platform.
- User onboarding must occur inside the web platform.
- Document uploads must be designed for the web platform.
- Future dashboards, user areas and AI interfaces belong to the web platform.

## Telegram Status

Telegram may exist only as:

- legacy access
- an optional communication channel
- a temporary bridge

Telegram is NOT:

- the primary platform
- the primary onboarding path
- the primary AI interface
- the primary user journey

## Official User Journey

```
Homepage
   |
   v
Welcome Flow
   |
   v
Center Sections
   |
   v
AI Center Chat
   |
   v
Personal Routes
   |
   v
Center Services
```

## Development Rule

When evaluating future features, the default question must be:

> "How does this work inside the website?"

not

> "How does this work inside Telegram?"

## Non-Goal

Do not remove existing Telegram references yet.

This document establishes future direction only.
